# Тривиальные названия веществ — ЕГЭ по химии

`index.html` содержит интерфейс, стили, программу и всю колоду. Скачайте файл и на компьютере откройте его в браузере с включённым JavaScript. Локальная копия работает без интернета. Дополнительный файл `sw.js` нужен только для автономного открытия опубликованной страницы.

## Как заниматься

1. Раскройте «Параметры колоды». Выберите направление, смешанный режим или случайный порядок и отметьте нужные разделы. Нажмите «Начать колоду», чтобы применить настройки.
2. Вспомните ответ и коснитесь карточки. На обратной стороне появятся ответ и пояснение из таблицы.
3. Нажмите «Знаю», если вспомнили ответ, или «Повторить», если ошиблись. Тренажёр автоматически покажет следующую карточку. Само раскрытие карточки не меняет оценку.
4. Кнопка «Назад» возвращает предыдущую карточку и отменяет выставленную ей оценку. В конце колоды можно повторить ошибки этой тренировки.
5. Фильтр «Только „Не знаю“» собирает карточки, для которых последней оценкой было «Повторить». Карточки без оценки в этот режим не входят.

## Как открыть на iPhone

### В Safari

1. Разместите `index.html` и `sw.js` в одной папке статического хостинга по инструкции ниже. Откройте HTTPS-ссылку в обычной вкладке Safari, пока есть интернет, и дождитесь отметки «Офлайн доступен». Браузер автоматически сохранит страницу для последующего открытия без сети.
2. Чтобы добавить значок, откройте меню «Поделиться» и выберите «На экран „Домой“». Если доступен переключатель «Открыть как веб-приложение», включите его, затем нажмите «Добавить». В первый раз запустите тренажёр со значка при подключении к интернету и тоже дождитесь отметки «Офлайн доступен». [Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/27/ios/27)
3. Включите авиарежим, отключите Wi-Fi, если он остался включён, и откройте тренажёр снова тем же способом. Обычная вкладка Safari и веб-приложение с экрана «Домой» могут хранить оценки отдельно. Используйте один способ входа, чтобы видеть свою историю. [О политике хранения WebKit](https://webkit.org/tracking-prevention/)

### Из скачанного файла без интернета

1. Сохраните `index.html` на самом iPhone. Если файл в iCloud Drive, перенесите его в папку «На iPhone», пока есть связь. [Где найти загрузки](https://support.apple.com/ru-ru/102440)
2. Откройте файл в приложении, которое поддерживает запуск JavaScript из локального HTML. Импорт обычно доступен в меню «Поделиться» или из самого просмотрщика.
3. Если карточка в системном предпросмотре «Файлов» не реагирует на касание, откройте импортированную копию в просмотрщике. Отметьте одну карточку, закройте просмотрщик и откройте ту же копию снова, чтобы проверить сохранение оценки. Доступность `localStorage` для `file://` зависит от программы. [Стандарт URL](https://url.spec.whatwg.org/#origin) · [Стандарт Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html#dom-localstorage-dev)

## Прогресс

Оценки записываются для каждого вещества в `localStorage`. В обычном режиме браузера они сохраняются после закрытия и повторного открытия по тому же адресу, пока браузер хранит данные сайта. Очистка данных сайта удаляет оценки. Для сброса из тренажёра выберите «Сбросить прогресс» и подтвердите действие.

## Статический хостинг

- **GitHub Pages.** Загрузите `index.html` и `sw.js` в корень репозитория. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main` и папку `/(root)`. После публикации откройте адрес из настроек Pages. [Документация GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- **Netlify Drop.** Поместите оба файла в отдельную папку и перетащите папку в Netlify Drop. По завершении откройте адрес сайта, который выдаст Netlify. [Документация Netlify](https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/)
- **Другой статический хостинг.** Загрузите оба файла в каталог публикации. Хостинг должен отдавать `index.html` как HTML, а `sw.js` как JavaScript, по HTTPS. Настройка сборки и серверный код не требуются.

## Отчёт по данным

Источником послужили семь таблиц файла «Тривиальные_названия_веществ_ЕГЭ.pdf». Каждая строка таблицы стала отдельной карточкой. Два независимых извлечения совпали по порядку строк, названиям, формулам, пояснениям и разделам.

Название с несколькими вариантами хранится целиком. Переносы внутри формул лавсана и нейлона сшиты без пробела. Сохранены нижние индексы, скобки, обозначения растворов, кристаллогидратов и связей. В PDF нет формул с явно записанным зарядом. Значения «Смесь» и «Полимер» перенесены из столбца «Формула». Для совпадающих формул в обратном режиме помогают раздел и подсказка из пояснения.

## Проверка

- В Edge (Chromium) без сети прошли все 137 карточек в обоих направлениях на ширине 320 px. Проверены формулы, названия, пояснения и границы обеих сторон карточки.
- Проверены узкие экраны 320 и 360 px, мобильный профиль iPhone 15 Pro Max шириной 430 px, планшет и рабочий стол. Проверены отступы safe-area, светлая и тёмная темы, переворот касанием и отсутствие горизонтальной прокрутки.
- Проверены смешанный режим, случайный порядок, выбор нескольких разделов, отбор «Не знаю», отмена оценки, счётчики, повтор ошибок и подтверждение сброса.
- Проверено восстановление оценок и позиции после перезагрузки и повторного открытия браузера с тем же профилем. Для опубликованного варианта отдельно проверено повторное открытие без сети после установки `sw.js` на локальном тестовом хосте.
- Safari на физическом iPhone в этой среде не проверялся.
